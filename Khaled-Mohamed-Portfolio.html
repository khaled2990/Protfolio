I'm Khaled Mohamed, a Junior Software Engineer and .NET Backend Developer from Egypt. I graduated from Sohag University's Computer Science program with a Very Good grade, and I focus on building secure, high-performance, and maintainable backend systems — the part of the product users never see but always depend on.

My core stack is C# and ASP.NET Core, built around Clean Architecture, Design Patterns, and SOLID principles, with Entity Framework Core and LINQ for working efficiently with data on SQL Server and Redis.

I'm comfortable rounding out a feature end-to-end with HTML, CSS, and JavaScript — including building responsive interfaces — and I version and collaborate on everything through GitHub. I care about code that's easy to read a year from now, APIs that fail predictably, and systems that hold up under real traffic.
